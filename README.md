# Assignment First GitHub

This is my first GitHub assignment project created using HTML and CSS.  
The project is simple and beginner-friendly, built to practice basic web development concepts and GitHub repository management.


## Project Overview

This project contains a simple blog-style webpage with multiple sections, headings, paragraphs, and list items.  
It helped me improve my understanding of webpage structure and external CSS styling.


## Technologies Used

- HTML5
- CSS3
- Git
- GitHub


## Features

- Simple and clean design
- Header section with title
- Multiple blog sections
- Ordered list section
- External CSS styling
- Reusable CSS classes
